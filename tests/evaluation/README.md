# Writing grading calibration fixtures

Put developer-reviewed IELTS samples in this directory. Each fixture should contain the exact task, learner essay, expected criterion bands, and human notes. Calibration should compare Gemini output against the expected bands and track exact matches, within-0.5 matches, and criterion-level disagreement.

These fixtures are development/evaluation data only. They are not user-visible training claims and the application never claims that AI grading is perfectly accurate.
